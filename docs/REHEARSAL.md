## 2. 黄金路径彩排（跑 3 遍）

### 第 1 遍：照稿念（计时）

| 步骤 | 操作 | 应看到 | 参考耗时 |

### 第 2 遍：换成自己说的话

- **不要**背稿，用你自己的口音/说法再走一遍——验证容错（标点、大小写都无所谓）。
- 重点观察：纠错是否**只纠语法**、不挑标点；Maya 是否**不跳戏**。

### 第 3 遍：故意制造故障

| 故障 | 制造方式 | 期望行为 |
|---|---|---|

| 顺便演示兜底 | 点右上角「回放」 | 按钮变 `▶ 回放中`，同样的路径照样走完 |

## 3. 话术对齐（避免自相矛盾）

演示时**别说**这几句，会和实现冲突：

| ❌ 别说 | ✅ 改说 |
|---|---|
| 「我们有四个独立 Agent 服务」 | 「一个编排器 + 三个专职模块」 |
| 「AI 会自动记住你上次说的话」 | 「画像跟着你走，但 NPC 始终是第一次见你」 |
| 「它能纠正标点」 | 「只纠语法词汇，不挑标点大小写」 |
| 「支持全球地图」 | 「demo 只开放伦敦，地图是内容入口」 |

## 4. 评审可能问的三个问题（提前备好答案）

**Q：这和直接用 ChatGPT 聊天有什么区别？**
> 三个差异，都可现场演示：① 纠错是**人物口吻**的，不跳戏；② 画像**跨 NPC 生效**但 NPC 不「认出」你；③ 纠错结果变成**课后卡 + 文明档案**，是可积累的学习资产。

**Q：多 Agent 体现在哪？**
> 打开 Trace 面板——`memory → tutor → npc → profile` 每一步都能看到输入输出。tutor 先产出 `corrected`，npc 只引用它，保证两层纠错说的是同一个错。

**Q：怎么保证不瞎编文化内容？**
> 每个 NPC 有人工审校的人设卡（身份/性格/事实边界/禁止话题），模型只能在卡内即兴；虚构人物明确标注，不冒充真实历史。

## 5. 兜底三级预案

| 级别 | 触发 | 动作 |
|---|---|---|
| L1 | 单次请求超时/限流 | 什么都不做，直接重发一次（已内置一次自动重试） |
| L2 | 连续失败 / 网络不稳 | 点「回放」→ 用剧本演完整条路径 |
| L3 | 页面彻底打不开 | 播放提前录好的屏幕录像，口头讲 Trace 面板 |

> **L2 的回放剧本涵盖**：错误句纠错、点单、兴趣 → 画像、切 Leo、通用追问。
> 演练时至少把 L2 完整走一遍，确保点下去就有反应。
